# Create DeletePlan Endpoint

## Setup Controller

### File: PlansController.cs
```csharp
[HttpDelete("{id}")]
public async Task<IActionResult> DeletePlan( [FromRoute]int id)
{
    await mediator.Send(new DeletePlanCommand(id));
    return NotFound();
}
```

**Behavior**
- Receives DELETE request.
- Extracts id from route.
- Sends DeletePlanCommand to MediatR.
- Returns HTTP response.

# Setup Command File

`In Application Module`

### File: Plans/Commands/DeletePlan/DeletePlanCommand.cs

```csharp
namespace PlanService.Application.Plans.Commands.DeletePlan;

public class DeletePlanCommand(int id) : IRequest
{
    public int Id { get; set; } = id;
}
```
Purpose

Represents a command in the CQRS pattern responsible for deleting a Plan.

Characteristics
- Implements IRequest
- Contains only the data required to perform deletion
- Does not return a response

`In Application Module`

### File: Plans/Commands/DeletePlan/DeletePlanCommandHandler.cs

```csharp
namespace PlanService.Application.Plans.Commands.DeletePlan;

public class DeletePlanCommandHandler(ILogger<DeletePlanCommandHandler> logger,
    IPlanRepository planRepository): IRequestHandler<DeletePlanCommand>
{
    public async Task Handle(DeletePlanCommand request, CancellationToken cancellationToken)
    {
        logger.LogInformation($"Deleting plan {request.Id}");
        var planToDelete = await planRepository.GetByIdAsync(request.Id);
        if (planToDelete == null)
        {
            throw new ApplicationException($"Plan with id {request.Id} not found");
        }
        await planRepository.DeletePlan(planToDelete);
    }
}
```

**Responsibilities**
- Logs deletion attempt
- Retrieves entity by ID
- Validates existence
- Calls repository to delete entity

**Execution Flow**
- Log deletion request
- Fetch Plan using repository
- If Plan does not exist → throw exception
- If Plan exists → delete Plan

## Setup IPlanRepository and PlanRepository

`In Domain Module`

### File: IPlanRepository

Add this line:
```csharp
Task DeletePlan(Plan entity);
```

**Purpose**

Defines contract for deleting a Plan.

Design Principle
- Domain defines behavior contract.
- Infrastructure provides implementation.
- Maintains dependency inversion.

`In Infrastructure Module`

### File: PlanRepository

```csharp
public async Task DeletePlan(Plan entity)
{
    dbContext.Plans.Remove(entity);
    await dbContext.SaveChangesAsync();
}
```

**Responsibilities**
- Marks entity for deletion
- Persists changes to database

**Database Operation**

Internally executes SQL DELETE statement when SaveChangesAsync() is called.
