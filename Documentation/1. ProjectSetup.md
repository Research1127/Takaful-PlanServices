
## PROJECT SETUP

1. Create Solution File
2. Add 4 clean architecture class library project
- Api
- Application
- Domain
- Infrastructure
3. Add References
```yaml
Api             => reference to Domain, Application and Infrastructure
Application     => reference to Domain
Infrastructure  => reference to Domain and Application
```
4. Install Entity Framework in `Infrastructure Module`
```csharp
Microsoft.EntityFrameworkCore.SqlServer 
```
5. Install `Microsoft.EntityFrameworkCore.Design` in `Api Module`
6. Create Connection to the database
   - Run Docker
   - Run below command in terminal
```shell
docker run --platform linux/amd64 -e 'ACCEPT_EULA=Y' -e 'SA_PASSWORD=yourpassword' -p 1433:1433 --name sqlserver -d mcr.microsoft.com/mssql/server:2022-latest
```
7. Install sql server extension in vscode if use vscode
```yaml
Search and install:
SQL Server (mssql) — by Microsoft
```

8. Open connection dialog and fill in the detail:
- Server = localhost,1433
- Authentication = SQL Login
- Username = sa
- Password = your pasword
- Database = (leave empty)

9. Create Your First Database (Plan Service)
```sql
CREATE DATABASE PlanServiceDb;
GO
```

10. Create Entities/Plan.cs file in Domain Module
```csharp
namespace PlanService.Domain.Entities;

public class Plan
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Description { get; set; }
    public decimal ContributionAmount { get; set; }
    public decimal CoverageAmount { get; set; }
    public int MinEntryAge { get; set; }
    public int MaxEntryAge { get; set; }
    public int WaitingPeriodDays { get; set; }
    public bool IsActive { get; set; }
    public DateTime CreatedAt { get; set; }
    public DateTime? UpdatedAt { get; set; }
}
```

11. Create `Persistence/PlanDbContext.cs` in `Infrastructure Module`
```csharp
using Microsoft.EntityFrameworkCore;
using PlanService.Domain.Entities;

namespace PlanService.Infrastructure.Persistence;

public class PlanDbContext : DbContext
{
    public PlanDbContext(DbContextOptions<PlanDbContext> options) : base(options)
    {
        
    }
    
    public DbSet<Plan> Plans { get; set; }
}
```
12. Add Connection String (appsettings.Development.json)
```csharp
"ConnectionStrings": {
    "DefaultConnection": "Server=localhost,1433;Database=PlanServiceDb;User Id=sa;Password=yourpassword;TrustServerCertificate=True;"
  },
```
13. Create `Extensions/ServiceCollectionExtensions.cs` in `Infrastructure layer` and register the `PlanDbContext` there and register the connection
```csharp
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;
using PlanService.Infrastructure.Seeders;
using PlanService.Infrastructure.Persistence;

namespace PlanService.Infrastructure.Extensions;

public static class ServiceCollectionExtensions
{
    public static void AddInfrastructure(this IServiceCollection services, IConfiguration configuration)
    {
        var connectionString = configuration.GetConnectionString("DefaultConnection");
        services.AddDbContext<PlanDbContext>(options => options.UseSqlServer(connectionString));
        
    }
}
```
14. Register the extensions in `program.cs`
```csharp
builder.Services.AddInfrastructure(builder.Configuration);

```

15. Do migration
```shell
dotnet ef migrations add InitialCreate -p ./PlanService.Infrastructure -s ./PlanService 
dotnet ef database update -p ./PlanService.Infrastructure -s ./PlanService
```

2. Extract the interface
```csharp
namespace PlanService.Infrastructure.Seeders;

public interface IPlanSeeder
{
    Task Seed();
}
```
3. Register in ServiceCollectionExtensions
```csharp
services.AddScoped<IPlanSeeder, PlanSeeder>();
```
4. Add Scoped in program.cs
```csharp
var scope = app.Services.CreateScope();
var seeder = scope.ServiceProvider.GetRequiredService<IPlanSeeder>();
await seeder.Seed();
```
