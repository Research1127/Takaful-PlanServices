# Automated Testing For CreatePlanCommandHandler

This document explains how to unit test the CreatePlanCommandHandler in the Application layer using mocking.

---

#### 🧠 What Are We Testing Here?

We are NOT testing:
- AutoMapper configuration
- Repository implementation
- Database

We are testing that:
1.	Logger is called
2.	Mapper is called
3.	Repository is called
4.	Returned ID is correct

---

#### 📦 Required Packages:

In your test project:
```yaml
Moq
FluentAssertions
xUnit
```

Purpose of Each Package
- xUnit → Test framework
- Moq → Mock dependencies
- FluentAssertions → Clean and readable assertions

---

## Testing Implementation

```csharp
namespace PlanService.Application.Tests.Plans.Commands.CreatePlan;

[TestSubject(typeof(CreatePlanCommandHandler))]
public class CreatePlanCommandHandlerTests
{

    [Fact]
    public async Task Handle_ForValidCommand_ReturnsCorrectId()
    {
        // Arrange ------------------------------
        
        // ILogger part
        var loggerMock = new Mock<ILogger<CreatePlanCommandHandler>>();
        
        // IMapper part
        var command = new CreatePlanCommand();
        var plan = new Plan();
        var mapperMock = new Mock<IMapper>();
        mapperMock.Setup(m => m.Map<Plan>(command)).Returns(plan);
        
        // Repository part
        var repositoryMock = new Mock<IPlanRepository>();
        repositoryMock.Setup(repo => repo.CreatePlan(It.IsAny<Plan>())).ReturnsAsync(1);


        
        var commandHandler = new CreatePlanCommandHandler(loggerMock.Object, mapperMock.Object, repositoryMock.Object);

        // act ------------------------------

        var result = await commandHandler.Handle(command, CancellationToken.None);

        // assertion ------------------------------
        result.Should().Be(1);
    }
}
```

---

# 🔍 Step-by-Step Explanation

## Arrange Phase

This is where we prepare everything needed for the test.

### Mocking ILogger
```csharp
var loggerMock = new Mock<ILogger<CreatePlanCommandHandler>>();
```
We create a fake logger because we don’t want real logging behavior during unit testing.

---

### Mocking IMapper
```csharp
var command = new CreatePlanCommand();
var plan = new Plan();
var mapperMock = new Mock<IMapper>();

mapperMock.Setup(m => m.Map<Plan>(command)).Returns(plan);
```

Here we are telling Moq:
```yaml
When Map<Plan>(command) is called, return plan.
```

We are not testing AutoMapper configuration.

We only simulate its behavior.

---

### Mocking Repository
```csharp
repositoryMock.Setup(repo => repo.CreatePlan(It.IsAny<Plan>())).ReturnsAsync(1);
```

Important:

It.IsAny<Plan>() means:
- Accept any Plan object.

ReturnsAsync(1) means:
- Simulate database returning ID = 1.

Since CreatePlan() returns Task<int>, we must use ReturnsAsync.

---


### Creating the Handler
```csharp
var commandHandler = new CreatePlanCommandHandler(
    loggerMock.Object,
    mapperMock.Object,
    repositoryMock.Object);
```

We inject the mocked dependencies into the handler.

This isolates the handler completely.

---

## Act Phase

```csharp
var result = await commandHandler.Handle(command, CancellationToken.None);
```
We call the real Handle() method.

Because the method is async, we must use await.

---

## Assert Phase
```csharp
result.Should().Be(1);
```

We verify that the returned ID is 1.

This confirms:
- Repository was called
- Value returned from repository is passed back correctly
