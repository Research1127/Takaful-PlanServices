# Create GetPlanById Endpoint.md

## Add GetPlanById Endpoint

### File: PlansController.cs
```csharp
[HttpGet("{id}")]
    public async Task<IActionResult> GetPlan([FromRoute]int id)
    {
        var plan = await mediator.Send(new GetByIdQuery(id));
        if (plan == null)
        {
            return NotFound();
        }
        return Ok(plan);
    }
```

Explanation
- [HttpGet("{id}")] defines a GET endpoint that accepts an id parameter.
- mediator.Send(new GetByIdQuery(id)) sends the query to MediatR.
- If no plan is found, NotFound() (HTTP 404) is returned.
- If the plan exists, it returns Ok(plan) (HTTP 200).

This keeps the controller thin and delegates business logic to the Application layer.

## Create Command File

`In Application Module`
### File: Plans/Queries/GetByIdQuery/GetByIdQuery.cs

```csharp
using MediatR;
using PlanService.Application.Plans.Dtos;


namespace PlanService.Application.Plans.Queries.GetByIdQuery;

public class GetByIdQuery(int id) : IRequest<PlanDto?>
{
    public int Id { get; set; } = id;
}
```
Explanation
- GetByIdQuery represents a request to retrieve a plan by its ID.
- It implements IRequest<PlanDto?>.
- PlanDto? means the query may return:
- A PlanDto if found
- null if no plan exists

`In Application Module`
### File: Plans/Queries/GetByIdQuery/GetByIdQueryHandler.cs

```csharp
using AutoMapper;
using MediatR;
using Microsoft.Extensions.Logging;
using PlanService.Application.Plans.Dtos;
using PlanService.Domain.Repositories;

namespace PlanService.Application.Plans.Queries.GetByIdQuery;

public class GetByIdQueryHandler(ILogger<GetByIdQueryHandler> logger,
    IMapper mapper, IPlanRepository planRepository) : IRequestHandler<GetByIdQuery,PlanDto?>
{
    public async Task<PlanDto> Handle(GetByIdQuery request, CancellationToken cancellationToken)
    {
        logger.LogInformation($"Get Plan ID {request.Id}");
        var plan = await planRepository.GetByIdAsync(request.Id);
        var planDto = mapper.Map<PlanDto>(plan);
        return planDto;
        
    }
}
```

Explanation:

```csharp
IRequestHandler<GetByIdQuery,PlanDto?>
```

**This means:**
- GetByIdQuery → The request type being handled.
- PlanDto? → The response type returned by the handler.

**In simple terms:**

This handler processes a GetByIdQuery and returns a PlanDto (or null).

## Add Interface

`In Domain Module`

### File: Repositories/IPlanRepository.cs

Add this line:
```csharp
Task<Plan?> GetByIdAsync(int id);
```

Explanation
- Returns Plan?
- null means no plan exists with the given ID
- Keeps domain logic independent from infrastructure

`In Infrastructure Module`

### File: Repositories/IPlanRepository.cs

Implement the method:

```csharp
public async Task<Plan?> GetByIdAsync(int id)
{
    var plan = await dbContext.Plans.FirstOrDefaultAsync(p => p.Id == id);
    return plan;
}
```
Explanation
- Uses EF Core to retrieve the plan.
- FirstOrDefaultAsync returns null if not found.
- Matches the nullable return type in the interface.
