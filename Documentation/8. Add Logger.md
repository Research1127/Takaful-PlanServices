# Adding Logger (Serilog)

This section explains how to configure Serilog for logging in the API module.
The configuration logs application events to:

- Console (with colored output)
- File system (daily rolling log file)

---
## Installation

In `Api module`, add nuget package called:
```csharp
Serilog.AspNetCore
```
This package integrates Serilog into the ASP.NET Core logging pipeline.

---


## Configure Serilog in Program.cs

### File: Program.cs
```csharp
// Serilog Part
builder.Host.UseSerilog((context, configuration) => configuration
    .WriteTo.Console(theme: AnsiConsoleTheme.Code,
        outputTemplate: "[{TimeStamp: dd:MM:yyyy HH:mm:ss} {Level:u3}] {Message:lj}{NewLine}{Exception}]")
    .ReadFrom.Configuration(context.Configuration));
```
Explanation
- UseSerilog(...) replaces the default ASP.NET Core logger with Serilog.
- .WriteTo.Console(...) enables logging to the console.
- AnsiConsoleTheme.Code enables colored log output for better readability during development.
- outputTemplate defines the format of each log entry.
- .ReadFrom.Configuration(...) allows additional configuration (such as file logging) to be read from appsettings.

Notes:

- For Console we can put in the appsettings.Development.json also but I didn't put because the console color
not showing nice color

## Configure File Logging

### File: appsettings.Development.json

```csharp
"Serilog": {
    "WriteTo": [
      {
        "Name": "File",
        "Args": {
          "path": "Logs/Plans-Api-.log",
          "rollingInterval": "Day",
          "rollOnSizeLimit": true
        }
      }
    ]
}
```

Explanation
- "Name": "File" enables file-based logging.
- "path" specifies the log file location.
- "rollingInterval": "Day" creates a new log file every day.
- "rollOnSizeLimit": true creates a new file if the current file exceeds the size limit.

Log files are stored inside the Logs folder at the root of the project.
