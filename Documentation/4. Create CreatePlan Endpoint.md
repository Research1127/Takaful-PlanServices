# Create CreatePlan Endpoint

## Configure PlanController

Add CreatePlan endpoint

### File: PlansController.cs
```csharp
[HttpPost]
public async Task<IActionResult> CreatePlan(CreatePlanCommand command)
{
    int id = await mediator.Send(command);
    return CreatedAtAction(nameof(GetPlanById), new {id}, null);
}
```

Explanation
- [HttpPost] defines an endpoint for creating a new plan.
- The controller receives CreatePlanCommand from the request body.
- mediator.Send(command) sends the command to MediatR.
- The handler returns the newly created plan’s id.
- CreatedAtAction(...) returns:
- HTTP 201 Created
- A Location header pointing to GetPlanById
- No response body (null)

## Create Command Files

In `Application Module`

### File: Plans/Commands/CreatePlanCommand.cs
```csharp
using MediatR;

namespace PlanService.Application.Plans.Commands;

public class CreatePlanCommand : IRequest<int>
{
    public string Name { get; set; }
    public string Description { get; set; }
    public decimal ContributionAmount { get; set; }
    public decimal CoverageAmount { get; set; }
    public int MinEntryAge { get; set; }
    public int MaxEntryAge { get; set; }
}
```
Explanation
- Represents a request to create a new plan.
- Implements IRequest<int>.
- int represents the ID of the newly created plan.
- This is a Command (modifies state).

In `Application Module`

### File: Plans/Commands/CreatePlanCommandHandler.cs
```csharp
using AutoMapper;
using MediatR;
using Microsoft.Extensions.Logging;
using PlanService.Domain.Entities;
using PlanService.Domain.Repositories;

namespace PlanService.Application.Plans.Commands;

public class CreatePlanCommandHandler(ILogger<CreatePlanCommandHandler> logger,
    IMapper mapper, IPlanRepository planRepository) : IRequestHandler<CreatePlanCommand, int>
{
    public async Task<int> Handle(CreatePlanCommand request, CancellationToken cancellationToken)
    {
        logger.LogInformation("Creating a new plan");
        var plan = mapper.Map<Plan>(request);
        int id = await planRepository.CreatePlan(plan);
        return id;
    }
}
```
Explanation

IRequestHandler<CreatePlanCommand, int> means:
- CreatePlanCommand → Request type
- int → Response type (newly created ID)

Flow Inside Handler
1.	Logs creation activity.
2.	Maps command → domain entity.
3.	Calls repository to persist the entity.
4.	Returns the generated ID.

In `Infrastructure Module`

### File: Repositories/PlanRepository.cs

```csharp
public async Task<int> CreatePlan(Plan entity)
{
    dbContext.Plans.Add(entity);
    await dbContext.SaveChangesAsync();
    return entity.Id;
}
```

Explanation
- Adds entity to DbContext.
- Calls SaveChangesAsync() to persist to database.
- EF Core automatically generates the identity value.
- Returns the newly created ID.
